# Evaluasi Bahasa Indonesia Kelas IV SD: Ide Pokok dan Ide Pendukung

Repositori ini berisi perangkat **Soal Evaluasi Pembelajaran Bahasa Indonesia Kelas IV SD (Kurikulum Merdeka)** dengan topik **Ide Pokok dan Ide Pendukung**.

## Tujuan Pembelajaran
Melalui evaluasi ini, peserta didik diharapkan mampu:
1. Mengidentifikasi kalimat utama dan kalimat penjelas dalam suatu paragraf.
2. Menentukan **ide pokok** dari teks bacaan atau paragraf (baik deduktif maupun induktif).
3. Menentukan **ide pendukung** yang menjelaskan ide pokok dalam paragraf.
4. Menyajikan kembali ide pokok dan ide pendukung dari sebuah teks bacaan secara tepat.

## Daftar Berkas
- [`soal-evaluasi.md`](soal-evaluasi.md) — Naskah soal evaluasi lengkap (10 Pilihan Ganda, 5 Isian Singkat, dan 5 Uraian) siap cetak/bagikan.
- [`kunci-jawaban-dan-rubrik.md`](kunci-jawaban-dan-rubrik.md) — Kisi-kisi soal, kunci jawaban, pembahasan singkat, dan pedoman penskoran.
- [`index.html`](index.html) — Aplikasi **Kuis Evaluasi Interaktif** berbasis web (dapat dibuka langsung di browser atau diaktifkan melalui GitHub Pages).

## Cara Menggunakan Kuis Interaktif
1. Unduh atau buka [`index.html`](index.html) di browser (Chrome, Edge, Firefox, atau Safari).
2. Atau aktifkan **GitHub Pages** pada menu **Settings → Pages → Branch: `main` (`/ (root)`)** agar siswa dapat mengakses kuis secara daring.
3. Siswa mengisi nama dan kelas, mengerjakan soal Pilihan Ganda dan Isian Singkat, lalu melihat skor serta pembahasannya secara langsung.
